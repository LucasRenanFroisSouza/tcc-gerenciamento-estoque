# Sistema de Controle de Estoque de Fármacos

Projeto de TCC em desenvolvimento para gerenciamento de estoque da Medicina Nuclear da UNESP.

## Tecnologias

- Python
- Flask
- MySQL
- SQLAlchemy
- HTML
- CSS
- JavaScript
- JWT

## Funcionalidades

- Login de usuários
- Cadastro de fornecedores
- Cadastro de fármacos
- Controle de lotes
- Exclusão lógica de fármacos e lotes, com opção de visualizar e reativar itens inativos
- Controle de estoque
- Movimentações
